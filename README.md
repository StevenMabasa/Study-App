# Study-App
Create quizes from pdfs

# Deployed Link

https://jambaya-quiz-generator.netlify.app/ 
{Netlify for deploying frontend and
 Render for deploying backend}

# Environment Variables

Backend on Render:
- `GEMINI_API_KEY=your-new-gemini-api-key`

Frontend on Netlify:
- `REACT_APP_API_URL=https://your-render-backend-url`

Do not put the Gemini API key in the frontend or commit it to the repo.
